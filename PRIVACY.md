# Family Board — Privacy Policy

Family Board is a self-hosted household dashboard. It runs entirely on a
computer inside the household that installs it, and is used only by members of
that household. There is no hosted service, no accounts, and no operator other
than the household itself.

## What it accesses

With the household's consent, Family Board reads — and, when enabled, creates
and edits — events on the Google Calendars the household chooses to display,
using the Google Calendar API.

## Where that data goes

Nowhere. Calendar data is cached in a local database on the household's own
device so the board keeps working when the internet is down. It is not
transmitted to, stored by, or shared with anyone else, and there is no
analytics, advertising, or third-party service involved.

## Retention and revocation

Cached calendar data is refreshed continuously and can be deleted at any time
by removing the local database. Access can be revoked at any time at
<https://myaccount.google.com/permissions>, after which the board holds no
valid credential.

## Google API Services User Data Policy

Family Board's use of information received from Google APIs adheres to the
[Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy),
including the Limited Use requirements.

## Contact

Questions go to whoever installed the board in your house — this software has
no other operator.
